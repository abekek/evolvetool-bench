# decode_qlog_and_count_severity

## Description

Decode QLOG binary data from base64 and count log entries by severity level.

## Usage

```python
from decode_qlog_and_count_severity import decode_qlog_and_count_severity
result = decode_qlog_and_count_severity(<base64_data>)
print(result)
```

## Inputs
base64_data (str): Base64 encoded QLOG binary data
