# decode_arcsig_and_compute_spectrum

## Description

Decode an ARCSIG signal and compute its one-sided frequency spectrum.

## Usage

```python
from decode_arcsig_and_compute_spectrum import decode_arcsig_and_compute_spectrum
result = decode_arcsig_and_compute_spectrum(<arcsig_signal>)
print(result)
```

## Inputs
arcsig_signal (str): ARCSIG formatted signal string containing
                       version, sample rate, length, encoding, and data
