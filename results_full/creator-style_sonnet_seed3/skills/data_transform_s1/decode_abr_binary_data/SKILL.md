# decode_abr_binary_data

## Description

Decode ABR (custom binary) format data from base64 string to JSON array.

## Usage

```python
from decode_abr_binary_data import decode_abr_binary_data
result = decode_abr_binary_data(<base64_data>)
print(result)
```

## Inputs
base64_data (str): Base64 encoded ABR binary data
