# decode_abr_to_json

## Description

Decode ABR (Array-Based Record) format data from base64 and return as JSON array.

## Usage

```python
from decode_abr_to_json import decode_abr_to_json
result = decode_abr_to_json(<base64_data>)
print(result)
```

## Inputs
base64_data (str): Base64 encoded ABR format data
