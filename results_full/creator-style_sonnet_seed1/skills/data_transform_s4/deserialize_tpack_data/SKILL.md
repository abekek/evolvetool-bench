# deserialize_tpack_data

## Description

Deserializes TPACK (Tagged PACKed) binary data from base64 encoding.

## Usage

```python
from deserialize_tpack_data import deserialize_tpack_data
result = deserialize_tpack_data(<encoded_data>)
print(result)
```

## Inputs
encoded_data (str): Base64 encoded TPACK data string
