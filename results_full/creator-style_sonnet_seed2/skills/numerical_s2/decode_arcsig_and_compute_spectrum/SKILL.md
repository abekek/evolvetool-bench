# decode_arcsig_and_compute_spectrum

## Description

Decode an ARCSIG signal and compute its frequency spectrum using FFT.

## Usage

```python
from decode_arcsig_and_compute_spectrum import decode_arcsig_and_compute_spectrum
result = decode_arcsig_and_compute_spectrum(<arcsig_string>)
print(result)
```

## Inputs
arcsig_string (str): ARCSIG formatted string containing signal metadata and base64 encoded data
