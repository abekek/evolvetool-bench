# parse_vdl_schema

## Description

Parse a VDL (Validation Definition Language) schema into a structured representation.

## Usage

```python
from parse_vdl_schema import parse_vdl_schema
result = parse_vdl_schema(<vdl_content>)
print(result)
```

## Inputs
vdl_content (str): The VDL schema content as a string
