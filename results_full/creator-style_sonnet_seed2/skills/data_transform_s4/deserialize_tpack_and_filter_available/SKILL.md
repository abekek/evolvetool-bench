# deserialize_tpack_and_filter_available

## Description

Deserializes TPACK data from base64 and filters records where 'available' is True.

## Usage

```python
from deserialize_tpack_and_filter_available import deserialize_tpack_and_filter_available
result = deserialize_tpack_and_filter_available(<base64_data>)
print(result)
```

## Inputs
base64_data (str): Base64 encoded TPACK data containing product records
