# deserialize_tpack_data

## Description

Deserialize TPACK (Tag-Pack) binary data format from base64 encoded string.

## Usage

```python
from deserialize_tpack_data import deserialize_tpack_data
result = deserialize_tpack_data(<base64_data>)
print(result)
```

## Inputs
base64_data (str): Base64 encoded TPACK binary data
