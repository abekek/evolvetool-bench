# fit_arcfit_exp_decay_model

## Description

Fit an exponential decay model y = a * exp(-b * x) + c to the given data points and return fitted parameters.

## Usage

```python
from fit_arcfit_exp_decay_model import fit_arcfit_exp_decay_model
result = fit_arcfit_exp_decay_model(<model_spec>)
print(result)
```
