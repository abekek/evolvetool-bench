# decode_qlog_binary_data

## Description

Decode QLOG (Quantized Log Format) binary data into structured log records.

## Usage

```python
from decode_qlog_binary_data import decode_qlog_binary_data
result = decode_qlog_binary_data(<base64_data>)
print(result)
```

## Inputs
base64_data (str): Base64 encoded QLOG binary data
